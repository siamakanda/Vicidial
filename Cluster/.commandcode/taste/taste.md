# Taste

## Workflow
- When handed a folder/repo, expects the agent to first read and understand the whole project, then proactively review and fix any issues it finds — not just report them. Confidence: 0.6

## Documentation
- Expects a README that includes the how-to plus every command needed to download and run the scripts. Confidence: 0.6
- Prefers "easy to deploy" setups — favors one-command installs over multi-step manual instructions (e.g., `curl -sSL <url> | sudo bash`). Confidence: 0.6

## Domain / Tooling
- Works on VICIdial / Asterisk telephony cluster infrastructure, automating server and cron maintenance with bash shell scripts. Confidence: 0.7
